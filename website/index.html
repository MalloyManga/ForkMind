One canvas. Every useful direction.

ForkMind combines a visual knowledge workspace with practical AI context controls, without introducing another cloud account.

Branching conversations

Fork any card or selected passage into a focused follow-up while preserving the original chain.

Real reference context

Connect notes, URLs, images, Markdown, text, PDF, and DOCX files directly to an AI request.

Your provider, your data

Connect an OpenAI-compatible endpoint or local model. API keys remain in runtime memory.

Infinite visual workspace

Move, resize, connect, select, copy, and organize cards on a responsive tldraw-powered canvas.

Portable workspaces

Export, import, and share validated JSON workspaces while managed assets remain portable.

Markdown-native thinking

Write with GFM, syntax-highlighted code, and LaTeX while the canvas stays synchronized.

Local by default

Your workspace stays yours.

ForkMind is a desktop application. It does not require a ForkMind account or upload your canvas to a proprietary backend.

Local workspace storageConversation trees and managed assets are stored on your machine.
Runtime-only API keysYour AI provider key is cleared when the application closes.
Open source and inspectableThe implementation and data contracts are available on GitHub.
